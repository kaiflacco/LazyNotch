# LazyNotch — Brand Specification

## Brand

**Name:** LazyNotch

## Positioning

LazyNotch is a lightweight macOS utility that makes the notch useful without making the desktop feel busy.

The name communicates:

- notch-first interaction
- low effort
- convenience
- ambient utility

## Naming rules

Use:

- LazyNotch
- LazyNotch Shell
- LazyNotch Widgets
- LazyNotch Live
- LazyShelf
- LazyNotch Settings

Avoid using NotchNook in customer-facing LazyNotch copy except where legally/technically necessary for compatibility or comparison documentation.

## Product voice

Desired:

- concise
- calm
- clever
- native
- understated
- technical when necessary

Avoid:

- exaggerated claims
- "official" or "replacement" language
- implying affiliation with the reference product
- copying reference-product slogans

## Logo

Create an original LazyNotch mark.

Recommended concept direction:

- abstract notch silhouette
- subtle "L" geometry
- simple monochrome mark
- readable at menu-bar scale

Do not copy the reference product's logo.

## App metadata

Recommended:

```text
CFBundleDisplayName = LazyNotch
CFBundleName = LazyNotch
```

Bundle identifier should use the eventual developer domain, for example:

```text
com.example.LazyNotch
```

Replace `com.example` before distribution.

## About window

Suggested content:

```text
LazyNotch

A quiet utility surface for your Mac's notch.

Version X.Y.Z
© 2026 <Developer>
```

Do not state or imply that LazyNotch is made by or affiliated with the reference product's publisher.
